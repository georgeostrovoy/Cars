# Cars - Browser-first Side-Scroller Prototype

Ты прав: теперь проект сделан так, чтобы **сразу работать в браузере**.

## Рекомендованный запуск: Vercel
Самый удобный вариант для Android/планшета — задеплоить и открыть публичную ссылку.

1. Загрузи репозиторий в GitHub.
2. Открой `https://vercel.com/new`.
3. Импортируй репозиторий и нажми **Deploy**.
4. Открой выданный URL (игра открывается с `/`).

Подробные шаги: `DEPLOY_VERCEL.md`.

## Локальный запуск (если нужен)
Из корня репозитория:

```bash
python3 -m http.server 8080
```

Открой:
- `http://localhost:8080/web/`

## Управление
- `A / D` (или стрелки) — ехать
- `Space` — прыжок
- `R` — сброс машины

## Что уже есть
- Прототип фаз 1–2 теперь на Matter.js: rigid-body шасси, два колеса, constraints-подвеска, прыжок, воздушный контроль и камера-следование.
- Фаза 3 (база): зоны поверхностей (dirt/grass/sand/ice) влияют на сцепление.
- Чистая модульная структура кода для дальнейшего роста (уровни, прогресс, гараж, UI, контент).

## Структура
- `web/index.html` — входная страница.
- `web/src/core` — ввод и системные модули.
- `web/src/physics` — физика машины.
- `web/src/world` — ландшафт и покрытия.
- `web/src/ui` — рендер и HUD.
- `web/src/game` — игровой цикл и связка систем.
